## 📖 项目概述

## 📖 项目概述

本项目旨在构建一个基于深度学习的**产品表面缺陷视觉检测系统**，能够自动识别工业产品表面的各类瑕疵，替代传统人工目检，提升质检效率与一致性。

### 核心功能模块

| 功能模块 | 子功能 | 说明 |
| :--- | :--- | :--- |
| **1. 数据管理** | 数据采集与标注 | 支持图像采集、缺陷标注（划痕、凹陷、脏污、裂纹等） |
| | 数据增强 | 旋转、翻转、亮度调整、噪声添加等 |
| | 数据集划分 | 训练/验证/测试集按比例自动划分 |
| **2. 预处理** | 图像归一化 | 尺寸归一化、像素值标准化 |
| | 缺陷增强 | 针对小目标缺陷进行增强处理 |
| | 背景去除 | 去除无关背景，突出检测区域 |
| **3. 模型训练** | 目标检测 | YOLO / Faster R-CNN 等检测模型 |
| | 分类模型 | ResNet / EfficientNet 等分类模型 |
| | 异常检测 | PatchCore / PaDiM 等异常检测算法 |
| **4. 缺陷识别** | 缺陷定位 | 输出缺陷在图像中的位置（边界框） |
| | 缺陷分类 | 识别缺陷类型（划痕、凹陷、脏污等） |
| | 缺陷分级 | 根据严重程度进行等级判定 |
| **5. 结果输出** | 可视化展示 | 图像上绘制检测框和标签 |
| | 统计报表 | 生成检测报告（合格率、缺陷分布等） |
| | API接口 | 提供HTTP接口供其他系统调用 |
| **6. 系统管理** | 模型管理 | 模型版本管理、在线更新 |
| | 日志记录 | 检测记录存储与查询 |
| | 参数配置 | 检测阈值、IOU阈值等参数可调 |

- **项目目标**：---

### 🎯 项目目标

| 目标维度 | 具体描述 |
| :--- | :--- |
| **核心目标** | 开发一套可部署的产品表面缺陷自动检测系统，实现对划痕、凹陷、脏污、裂纹等常见缺陷的精准识别与定位 |
| **性能指标** | 检测精度 mAP ≥ 0.85，单张图片推理时间 ≤ 100ms，满足工业产线实时检测需求 |
| **应用目标** | 提供Web界面和API接口，便于与现有生产管理系统集成，降低人工质检成本 ≥ 50% |
| **研究目标** | 探索对比目标检测、分类、异常检测等不同技术路线在工业质检场景下的适用性与优劣势 |
